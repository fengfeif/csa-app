业务日志规范参考
1. 关键业务节点 — 用户登录 / 支付成功 / 订单创建 业务线索
业务日志用 INFO 级别，带 traceId 串起全链路。关键字包含 事件类型 event + 业务唯一标识 bizId。
// 登录成功 log.info("[{}] 用户登录成功 event=user.login userId={} sourceIp={} loginResult={}", traceId, userId, sourceIp, loginResult); // 登录失败（重点排查） log.warn("[{}] 用户登录失败 event=user.login.fail userId={} sourceIp={} failReason={}", traceId, userId, sourceIp, failReason); // 支付成功 log.info("[{}] 支付成功 event=payment.success orderId={} userId={} amount={} channel={}", traceId, orderId, userId, amount, channel); // 订单创建 log.info("[{}] 订单创建 event=order.create orderId={} userId={} amount={} goodsId={}", traceId, orderId, userId, amount, goodsId);
2. 外部交互 — 第三方API / 数据库 / 消息队列（入参出参+脱敏） 易出问题
一定记录入参和出参，注意脱敏（手机号/身份证/卡号/密码/Token 用 * 替换）。调用前打日志，返回后立刻打日志。
// 第三方 HTTP API log.info("[{}] 调用第三方API 发起 target={} method={} request={}", traceId, url, httpMethod, maskParams(requestParams)); log.info("[{}] 调用第三方API 返回 target={} status={} response={} costMs={}", traceId, url, httpStatus, maskParams(responseBody), costMs); // 数据库读写 log.info("[{}] 数据库查询 sql={} params={} rows={} costMs={}", traceId, maskedSql, maskParams(sqlParams), rowCount, costMs); // 消息队列收发 log.info("[{}] MQ发送 topic={} key={} message={} result={}", traceId, topic, msgKey, maskParams(messageBody), sendResult); log.info("[{}] MQ消费 topic={} key={} message={} consumeResult={}", traceId, topic, msgKey, maskParams(messageBody), consumeResult);
3. 异常与错误 — Exception / 非预期返回值（完整堆栈） 必须堆栈
ERROR 级别，必须传入异常对象（e）以输出完整 Stack Trace，不要只打 e.getMessage()。调用链路上下文一并记录。
// 捕获异常（带完整堆栈） log.error("[{}] 业务处理异常 event={} bizId={} params={}", traceId, "order.create", orderId, maskParams(orderReq), e); // 第三方调用异常 log.error("[{}] 第三方调用异常 target={} request={}", traceId, url, maskParams(request), e); // 非预期返回值 log.error("[{}] 非预期返回值 target={} expected={} actual={}", traceId, serviceName, "SUCCESS", actualResult);
4. 状态变更 — 缓存失效 / 配置热更新 / 定时任务 运行轨迹
状态变更用 INFO，记录 from→to 和触发源，便于回放运行轨迹。
// 缓存失效 log.info("[{}] 缓存失效 cacheKey={} reason={} reloadSource={}", traceId, cacheKey, "expired|evict|manual", reloadSource); // 配置热更新 log.info("[{}] 配置热更新 configKey={} oldValue={} newValue={} operator={}", traceId, configKey, maskValue(oldVal), maskValue(newVal), operator); // 定时任务触发 log.info("[{}] 定时任务触发 jobName={} triggerType={} start={}", traceId, jobName, "cron|manual", new Date()); log.info("[{}] 定时任务完成 jobName={} processCount={} costMs={}", traceId, jobName, processCount, costMs);
5. 性能指标 — 慢查询 / 接口耗时超阈值 性能预警
慢查询与超时用 WARN，记录耗时与阈值。SQL 超过阈值需单独告警。
// 接口耗时超阈值 log.warn("[{}] 接口耗时超阈值 api={} costMs={} thresholdMs={} traceId={}", traceId, apiPath, costMs, thresholdMs, traceId); // 慢 SQL log.warn("[{}] 慢SQL sql={} params={} costMs={} thresholdMs={}", traceId, maskedSql, maskParams(params), costMs, 1000); // 慢外部调用 log.warn("[{}] 外部调用慢 target={} costMs={} thresholdMs={}", traceId, url, costMs, 2000);
